# InvokeAI Simple Mode v1.0.0

The first public release of the unofficial InvokeAI Simple Mode community interface.

The release adds a visual node canvas around InvokeAI 6.13.8 and FLUX.2 Klein, including multi-reference editing, sequential variants, focus editing, result chaining, upscale/download actions, persistent workspaces, native InvokeAI action discovery, and a modern Windows launcher.

## Important

- Windows 10/11 only for v1.0.0.
- Requires an existing InvokeAI 6.13.8 installation.
- Model weights are not included.
- FLUX.2 Klein 9B has its own license and may require Hugging Face approval.
- HiDream support in the launcher is optional and separate from the node pipeline.
- This is an unofficial community project and is not endorsed by Invoke AI or Black Forest Labs.
