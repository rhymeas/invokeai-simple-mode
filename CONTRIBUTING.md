# Contributing

Bug reports and focused pull requests are welcome.

1. Reproduce the issue with InvokeAI 6.13.8.
2. Keep generated images, model weights, tokens, databases, and workspace files out of commits.
3. Run the checks documented in `README.md`.
4. Describe user-visible behavior and GPU/model assumptions in the pull request.

By contributing, you agree that your contribution is licensed under Apache-2.0.
